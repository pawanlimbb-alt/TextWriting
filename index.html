MyHand

Write each letter once in your own hand. Then type anything and get a full page that looks like you wrote it.

Pick a character

Start with a–z. Two or three versions of each letter make the result look natural. Missing characters fall back to a handwriting-style font.

Write “a”

Sit letters on the red line. Tall letters reach the top dashed line, small letters the middle one, and g, y, p drop below.

Saved versions (tap one to remove)

Import from a photo

Ruled notebook paper is fine. Write one set per line with gaps between letters, then take a straight, well-lit photo. Avoid joining letters together.
